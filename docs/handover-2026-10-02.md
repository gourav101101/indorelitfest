## Release

Prepared directory: `deployment/releases/indorelitfest-2026-10-02T06-12-48-479Z/`.

The release includes production `vendor/`, built assets, the updated content and hosting instructions. Local `.env`, development packages, research, database files and runtime caches are excluded. Configure the real domain, private production environment and public document root on the host, then follow [Hostinger deployment](hostinger-deployment.md). Preserve an existing site's APP_KEY. Production server checks and a live browser smoke test remain part of deployment; local checks do not prove the host is configured.

To generate a fresh source/build copy after later edits, run `node scripts/prepare-release.mjs`; install production Composer dependencies inside that copy as documented.
